# ICETASK3-Graph-Algorithms-Visualizer

## Project Description

The Graph Algorithms Visualizer is a Java Swing application that allows users to create and edit graphs and explore graph algorithms through a graphical user interface.

The application allows users to create vertices, connect them using weighted edges, and execute graph algorithms to understand how graphs are processed.

This project was developed as part of an Information Technology ICE task and focuses on Java development, graphical user interface design, graph modelling, algorithms, and version control.

## Problem the Software Solves

Understanding graph algorithms can be difficult when studying only theoretical concepts.

The Graph Algorithms Visualizer helps users understand graph structures and algorithms by displaying vertices, weighted edges, and algorithm results visually.

This makes it easier to explore graph traversal, shortest paths, and minimum spanning trees.

## Features

### Graph Creation

- Add vertices to the graph.
- Create weighted edges between vertices.
- Remove vertices and edges.
- View the graph through a Java Swing interface.

### Graph Algorithms

The application includes the following algorithms:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Algorithm
- Prim's Algorithm

### Algorithm Results

The application displays results from the selected algorithm.

Examples include:

- BFS traversal order.
- DFS traversal order.
- Shortest distances using Dijkstra's Algorithm.
- Parent links for Prim's Minimum Spanning Tree.

### Enhancement

The project is being enhanced with drag-and-drop vertex repositioning.

This feature allows users to move vertices around the graph to improve graph organisation and visualisation.

The enhancement is intended to make graph editing more interactive and user-friendly.

## How to Run the Application

1. Download or clone the project from GitHub.
2. Open the project in NetBeans or IntelliJ IDEA.
3. Ensure that Java is installed.
4. Open the Maven project using the pom.xml file.
5. Build the project.
6. Run GraphVisualizer.java.

## Usage Guide

### Adding Vertices

Select the option to add a vertex and click on the graph area.

Enter the vertex name when prompted.

### Adding Edges

Select Add Edge mode.

Click the first vertex and then the second vertex.

Enter the edge weight when prompted.

### Running Algorithms

Select the required algorithm from the Algorithms menu.

Choose a starting vertex when prompted.

View the algorithm result displayed by the application.
